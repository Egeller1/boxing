# Boxing Timer

A web-based boxing timer app with round timer, break timer, and vocalized random boxing move commands.

## Features

- Configurable round length, break length, and number of rounds
- Countdown timers with audio for both initial start and break periods
- Boxing bell sound at the beginning and end of each round
- Random boxing move announcements with configurable interval
- Adjustable voice speed for move announcements
- Ability to add custom moves
- Responsive design that works on both desktop and mobile

## How to Use

1. Set your desired round time, break time, and number of rounds
2. Adjust the move interval (how often moves are announced)
3. Adjust voice speed if needed
4. Click START to begin your workout
5. Use PAUSE/RESUME to control the timer
6. Use RESET to return to the setup screen

The timer includes:

- Audio countdown for the 10 seconds before the first round and during the last 10 seconds of each break
- A boxing bell that rings at the start and end of each round
- Voice announcements of random boxing moves during rounds
